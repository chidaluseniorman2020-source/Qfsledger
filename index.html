Need to know

Frequently asked questions

Is this a live cryptocurrency wallet?

No. This is a front-end website prototype. It does not hold private keys, connect to a blockchain or process cryptocurrency transactions.

Are the balances and prices real?

No. All balances, chart values and prices shown are sample content only.

What does account creation do?

If Supabase Authentication is configured, it can create an authentication account. That does not create a crypto wallet or enable transactions.
